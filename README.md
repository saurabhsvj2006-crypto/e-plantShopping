# Paradise Nursery Shopping Application

Paradise Nursery is an online plant shopping application that allows users to explore different categories of houseplants and purchase their favourite plants.

## Project Features
- Browse houseplants across different categories.
- View plant names, images, and prices.
- Add plants to a shopping cart.
- Increase or decrease plant quantities.
- Remove plants from the cart.
- Calculate the total cost of items in the cart.

## Technologies Used
- React
- JavaScript
- CSS
- Redux Toolkit

## Project Objective
The objective of this project is to develop a user-friendly online plant shopping application using React and Redux for state management.
